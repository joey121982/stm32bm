# STM32F103C8 Bare Metal
An experimental repository for my bare-metal STM32 bluepill code.
```boot``` contains a very simple custom bootloader, ```src``` contains the HAL & firmware.

## Prerequisites
* arm-none-eabi build tools
* st-flash
